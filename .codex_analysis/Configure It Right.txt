Introduction
Calculate It Right taught you how to size every component. Wire It Right taught you how to install everything safely. Configure It Right teaches you the third and final skill: how to connect every component together correctly, set up every inverter parameter precisely, and make every part of the system communicate and work as one.
A solar system that is correctly sized and properly installed but incorrectly configured will still fail to perform. The battery may be damaged by wrong charging voltage. The inverter may trip at peak load due to wrong working mode. Two parallel inverters may fight each other instead of working together. The BMS may shut down the battery because the communication cable is connected to the wrong port.
This book covers every configuration scenario you will encounter in the field: panel strings, battery banks, parallel inverters, three-phase systems, CAN bus and RS485 communication, hybrid inverter settings, working modes, generator integration, WiFi monitoring, system expansion, and fault code diagnosis. Brand-specific guidance for Deye, Growatt, SRNE, Voltronic, Victron, and Felicity is included throughout.
TIP: How to Use This Book
Read Chapters 1 to 6 first to understand the principles of configuration and communication. Then go to the specific brand chapter for your inverter (Chapters 7, 8, or 9). Use Chapters 10 to 13 for specific topics like working modes, generator setup, and three-phase. Keep Chapters 15 and 16 open on every job as your field reference.

Understanding Solar System Configurations
Before configuring any component, you must understand what type of system you are building and how all the components will work together. Every configuration decision you make downstream depends on getting this architecture decision right first.
Figure 1.1: All four solar system configurations from basic off-grid to parallel inverter. Each configuration has specific cable, port, and communication requirements covered in detail in this book.
1.1  Basic Off-Grid Configuration
The simplest configuration: one string of panels, one inverter with built-in MPPT, and one battery bank. No grid connection. All loads are powered exclusively by solar and battery. This configuration is used for remote sites with no grid access.

1.2  Expanded Off-Grid Configuration
When energy requirements grow beyond what a single panel string and battery can supply, the system is expanded. More panel strings are added (series-parallel configuration), the battery bank is expanded (parallel batteries), and a larger inverter may be required. This is the most common configuration for Nigerian residential off-grid installations.

1.3  Hybrid Single Inverter Configuration
A hybrid inverter connects to solar panels, battery bank, grid input, and loads simultaneously. It manages all four connections intelligently, prioritising solar, using battery when solar is insufficient, and drawing from grid when both solar and battery are low. This is the most common professional installation configuration.
Solar panels connect to the PV input terminals of the hybrid inverter via the built-in MPPT controller.
Battery connects to the BAT terminals. Communication cable (CAN or RS485) connects battery BMS to inverter.
Grid AC input connects to the AC-IN terminals. Inverter uses this to charge battery and supplement loads.
All loads connect to the AC-OUT terminals. Inverter manages which power source supplies these loads.
1.4  Parallel Inverter Configuration
When load requirements exceed the capacity of a single inverter, two or more identical inverters are connected in parallel. Each inverter handles a portion of the total load. A communication cable between the inverters synchronises their output so they work together as a single larger unit.
DANGER: Only Identical Inverters Can Be Paralleled
Never attempt to parallel inverters of different brands, models, or firmware versions. The communication protocol between parallel inverters is proprietary to each manufacturer. Mixing models creates communication conflicts that cause both inverters to malfunction and can permanently damage both units.
1.5  Three-Phase Configuration Overview
Three-phase systems use three inverters, one per phase, with a master-slave communication arrangement. Each inverter handles one phase of the three-phase supply. This configuration is required for three-phase loads such as industrial equipment, large commercial air conditioning, and three-phase motors. Full three-phase configuration is covered in Chapter 13.
KEY TAKEAWAYS
Choose the system configuration before purchasing any equipment
Basic off-grid: 1 string, 1 inverter, 1 battery bank, no grid
Hybrid: solar plus battery plus grid, all managed by hybrid inverter
Parallel inverters: ONLY same brand, same model, same firmware
Three-phase: 3 inverters in master-slave arrangement, one per phase
All configuration decisions affect cable sizes, port connections, and settings

Panel Configuration
How you connect solar panels together determines the voltage and current your inverter receives. Getting this wrong means the MPPT controller either cannot track properly (if voltage is too low) or is permanently destroyed (if voltage is too high). Panel configuration is not just about getting more power. It is about matching the output precisely to what the inverter can accept.
Figure 2.1: Three panel connection methods. Series adds voltage. Parallel adds current. Series-parallel combines both for higher voltage and higher current simultaneously.
2.1  Series Connection: Voltage and String Design
In a series connection, the positive terminal of each panel connects to the negative terminal of the next panel. The result is that voltage adds up while current stays the same as a single panel.
String Voltage = Number of Panels x Panel Voc   |   String Current = Single Panel Isc

String Voc must be BELOW inverter MPPT max input voltage

DANGER: Panel String Voc Exceeds Inverter Maximum
If you connect a panel string whose Voc exceeds the inverter MPPT maximum input voltage, the MPPT controller is destroyed instantly and permanently the first time the sun shines. This is not a warranty repair. Always calculate string Voc before connecting panels. Check the inverter datasheet for the maximum PV input voltage.
2.2  Parallel Connection: Current and Capacity
In a parallel connection, all positive terminals connect together and all negative terminals connect together. Current adds up while voltage stays the same as a single panel.
Parallel Current = Number of Panels x Panel Isc   |   Parallel Voltage = Single Panel Voc

COMMON MISTAKE: Parallel Panels Without Blocking Diodes
When panels are connected in parallel, a shaded panel can become a load drawing current from the unshaded panels rather than contributing to the string. Most modern panels have bypass diodes built in, but in a parallel configuration without string-level protection, a faulty panel can drain the entire array at night. Always use a combiner box with string fuses or blocking diodes for parallel strings above 3 panels.
2.3  Series-Parallel Combination
The series-parallel configuration achieves both higher voltage and higher current simultaneously. Multiple series strings (each string having the same number of panels in series) are connected in parallel with each other.

TIP: Always Use Equal String Lengths
In a series-parallel configuration, all strings must have the same number of panels. A string with 3 panels has a different voltage than a string with 2 panels. Connecting unequal strings in parallel causes current to flow from the higher voltage string into the lower voltage string, reducing output and potentially damaging panels.
2.4  MPPT String Design for Single and Dual MPPT
Modern hybrid inverters typically have one or two independent MPPT channels. Each MPPT channel independently tracks the maximum power point of the connected string. Dual MPPT inverters allow you to connect two independent strings with different orientations, tilt angles, or partial shading conditions.

2.5  Mixed Panel Configuration Rules
Mixing panels of different wattages, voltages, or brands in the same string is strongly discouraged. In a series string, the weakest panel limits the output of the entire string. In parallel strings, unequal voltages cause circulation currents that reduce output.
Never mix panels with different Voc values in the same series string.
Never mix panels with different Isc values in the same parallel string.
If mixing is unavoidable, connect each panel type to a separate MPPT input.
Document all panel specifications and configurations for future maintenance reference.
2.6  Tips and Common Mistakes in Panel Configuration
TIP: Test Each String Before Connecting to Inverter
Before connecting any panel string to the inverter, measure the open-circuit voltage of the string with a multimeter. Compare this to the calculated string Voc. If they match within 10%, the string is correctly wired. If Voc is lower than expected, check for a loose MC4 connection or a shaded panel. If Voc is higher than expected, you may have too many panels in the string.
COMMON MISTAKE: Using PV Cable for Battery Connections
Some installers use the orange UV-rated PV cable for battery connections because it is available on site. PV cable is designed for outdoor solar circuits and may not be rated for the continuous high current of battery-to-inverter connections. Always use flexible welding cable or purpose-made battery cable for battery connections.
KEY TAKEAWAYS
Series: voltage adds up, current stays the same. Always check string Voc against MPPT max
Parallel: current adds up, voltage stays the same. Size cables for total parallel current
Series-parallel: all strings must have equal numbers of panels in series
Dual MPPT allows independent strings on different orientations for better seasonal output
Never mix panels with different Voc or Isc in the same string or parallel group
Test every string Voc with a multimeter before connecting to the inverter

Battery Configuration
Battery configuration determines both the voltage and capacity of your battery bank. Getting the configuration wrong means either the wrong voltage to the inverter (causing immediate damage) or insufficient capacity for the required backup time. This chapter covers every battery connection method and the critical limits that must be observed.
Figure 3.1: Battery series and parallel configurations with maximum parallel limits and communication protocol options. Always verify battery communication type before purchasing an inverter.

Series connections are used to achieve the required system voltage from lower voltage batteries. Four 12V batteries in series produce 48V. Two 24V batteries in series produce 48V. The capacity in Ah remains the same as a single battery regardless of how many are connected in series.

DANGER: Exceeding Parallel Battery Limit Without Busbar
Connecting 5 or more Lithium batteries in parallel without a proper busbar system causes the batteries closest to the inverter connection point to carry more current than those further away. Always respect the manufacturer parallel limit.

3.5  Mixing Battery Brands and Ages
Every Lithium battery has slightly different internal resistance based on its age, chemistry, and state of health. When batteries of different brands or ages are mixed in the same parallel bank, the battery with the lowest internal resistance carries more current than the others. This accelerates its degradation while the others underperform.
Never mix Lithium batteries of different brands in the same bank.
Never mix Lithium batteries of significantly different ages (more than 12 months apart).
Never mix Lithium batteries of different capacities in the same bank.
Never mix Lithium and Lead-Acid batteries in the same bank under any circumstances.
3.6  Tips and Common Mistakes in Battery Configuration
PRO INSTALLER TIP
Always commission the inverter with a single battery first before expanding to a parallel bank. This allows you to verify that the single battery communicates correctly with the inverter, the BMS is functioning, and the charging voltage is correctly set. Expanding to a full parallel bank after individual verification is much easier to troubleshoot than commissioning a full bank at once.
COMMON MISTAKE: Connecting Battery Positive and Negative to Wrong Terminals
Battery polarity reversal is one of the most expensive mistakes in solar installation. Connecting battery positive to BAT negative on the inverter causes immediate destruction of the inverter's internal protection circuitry. Always verify polarity with a multimeter before making the final connection. Use colour-coded cables: red for positive, black for negative, and never deviate from this convention.
KEY TAKEAWAYS
Series: voltage adds up (4 x 12V = 48V), capacity stays the same
Parallel: capacity adds up (4 x 200Ah = 800Ah), voltage stays the same
Maximum 4 Lithium batteries in parallel without a busbar system
Never mix battery brands, ages, or capacities in the same bank
Never mix Lithium and Lead-Acid batteries in the same bank
Verify battery polarity with multimeter before every connection

Inverter Parallel Configuration
Connecting two or more inverters in parallel doubles or triples your system power capacity without requiring a single much larger inverter. But parallel inverter configuration is one of the most technically demanding operations in solar installation. The communication between parallel inverters must be exactly right or the inverters will fight each other rather than work together.
Figure 4.1: Single phase parallel (left) and three-phase configuration (right). All parallel inverters must be same brand, same model, and same firmware. Communication cable between inverters is mandatory.
4.1  Why and When to Parallel Inverters
Parallel inverters are used when the required system power exceeds the maximum capacity of a single inverter. A client who needs 10kVA output can use two 5kVA inverters in parallel rather than one 10kVA inverter. Parallel configurations also provide redundancy: if one inverter develops a fault, the other continues to supply loads at reduced capacity.

4.2  Single Phase Parallel Configuration
In single phase parallel, all inverters share the same AC output and the same battery bank. A dedicated communication cable between the inverters allows the master inverter to control the slave inverters, synchronising their output frequency, voltage, and phase so their AC outputs can be safely combined.
Identify which inverter will be MASTER. This is usually set in the inverter settings menu.
Connect the parallel communication cable from the COMMS port of the master to the COMMS port of slave 1. Continue daisy-chain for additional slaves.
Connect all inverters to the same battery bank. Each inverter has its own separate BAT+ and BAT- connection to the battery busbar.
Connect all inverter AC outputs to the shared AC busbar or distribution board.
Connect solar panel strings. Distribute strings evenly between inverters where possible.
Set each slave inverter to SLAVE mode in the settings. Power on master first, then slaves.
PRO INSTALLER TIP
When distributing panel strings between parallel inverters, try to give each inverter approximately the same number of panels so each MPPT operates at a similar power level. An inverter with significantly more panels than its parallel partner will reach maximum AC output and throttle its solar input while the other inverter operates below its capacity. Balanced panel distribution maximises total system output.
4.3  Three Phase Configuration
Three-phase configuration uses three identical inverters, one assigned to each phase (L1, L2, L3). The master inverter controls both slaves and ensures all three phases are synchronised in frequency, voltage, and phase angle. This is required for three-phase loads and large commercial installations.
Inverter 1 (Master): handles Phase L1. Set to Master in settings.
Inverter 2 (Slave 1): handles Phase L2. Set to Slave Phase 2 in settings.
Inverter 3 (Slave 2): handles Phase L3. Set to Slave Phase 3 in settings.
Communication cable connects all three inverters in daisy chain from master to slave 1 to slave 2.
Each inverter connects independently to the shared battery bank.
Output: 3-phase 380V or 415V (L1 to L2 to L3 to Neutral to Earth).

DANGER: Power On Sequence Must Be Correct
When starting a parallel system, always power on the MASTER inverter first. Wait for the master to fully initialise and display normal operation before powering on the first slave. Wait for the first slave to initialise before powering on the second slave. Powering on slaves before the master causes communication errors and may result in both inverters shutting down in fault state.
4.5  Communication Cable for Parallel Inverters
The parallel communication cable is a proprietary cable supplied by the inverter manufacturer. It is not a standard RJ45 Ethernet cable even though it uses the same connector. The pinout and protocol are specific to each manufacturer. Using the wrong cable or a generic Ethernet cable will cause the parallel system to fail.
TIP: Order the Parallel Cable When Ordering the Inverters
The parallel communication cable is sometimes sold separately and is not always included in the standard inverter package. When ordering parallel inverters, always explicitly request the parallel communication cable for that model at the time of order. Running a job without the correct cable and discovering this on installation day is an avoidable delay.
4.6  Tips and Common Mistakes in Parallel Configuration
COMMON MISTAKE: Running Parallel Inverters Without Communication Cable
Some installers attempt to run parallel inverters without the communication cable, thinking the AC outputs will synchronise automatically. They will not. Without the communication cable, each inverter generates its own AC output independently. When these outputs are connected together, the phase difference between them causes destructive circulating currents that can destroy both inverters within minutes.
KEY TAKEAWAYS
Only identical inverters can be paralleled: same brand, same model, same firmware
Communication cable between parallel inverters is mandatory. Never operate without it
In single phase parallel, all inverters share the same battery bank and AC output bus
In three-phase, each inverter handles one phase: L1 (master), L2 (slave 1), L3 (slave 2)
Power on sequence: master first, then slave 1, then slave 2
Load balance panel strings evenly between parallel inverters for maximum output
CHAPTER

Communication Cables and Ports
Communication cables are the nervous system of a modern solar installation. Without correct communication between the inverter and battery, the inverter uses its own internal assumptions for charging voltage and current, which are frequently incorrect for the specific battery installed. The result is a battery that is either overcharged or chronically undercharged, leading to premature failure.
Figure 5.1: All six communication cable types with connector types, protocols, compatible brands, and port functions. The RJ45 pin assignment at the bottom shows CAN Bus (pins 4 and 5) and RS485 (pins 1, 2, 3, 6) wiring.
5.1  CAN Bus Cable and Port Function
CAN (Controller Area Network) bus is the most advanced battery communication protocol used in solar systems. It is a bidirectional protocol that allows the battery BMS to send real-time data to the inverter and allows the inverter to send charge commands back to the BMS.
Data Sent by Battery BMS

The CAN bus cable uses RJ45 connectors. Pins 4 and 5 carry the CAN High and CAN Low signals respectively. The cable must be a twisted pair for pins 4 and 5 to maintain signal integrity over the cable length. Maximum recommended cable length is 5 metres between inverter and battery.
TIP: Always Enable CAN Communication in Both Inverter and Battery Settings
CAN communication must be enabled in the inverter settings AND in the battery BMS settings. Connecting the cable alone is not sufficient. In Deye inverters, go to Setting 05 and select the correct battery communication type. In Pylontech batteries, ensure the RS485 or CAN port is selected with the correct protocol in the battery management settings.
5.2  RS485 Cable and Modbus Protocol
RS485 is an older but still widely used serial communication protocol. It uses a two-wire differential signal (A+ and B-) that is highly resistant to electrical noise. Most solar inverters implement Modbus RTU protocol over RS485 for battery communication.
RS485 cable uses pins 1 and 2 (A+/TX+) and pins 3 and 6 (B-/TX-) of the RJ45 connector.
Maximum cable length: 100 metres at low data rates (much longer than CAN bus).
RS485 supports multiple devices on one bus (up to 32 devices in a chain).
Modbus device address must be set correctly. Default is usually address 1 or 2.
Termination resistor (120 ohm) required at the last device in a long RS485 chain.
5.3  Parallel Communication Cable
The parallel communication cable connects paired inverters to synchronise their output. This cable is proprietary to each manufacturer and must be the exact cable specified for the model. It is NOT a standard Ethernet cable. The signal it carries is specific to the inverter's parallel synchronisation protocol and operates at different voltage levels than standard Ethernet.

The dry contact port provides a simple two-wire signal output that can control external devices. When the battery is sufficiently charged, the inverter opens the dry contact and the generator stops.
TIP: Use a Relay for Generator Auto-Start
The dry contact on most inverters is a low-current signal (typically 12V DC at less than 100mA). Never connect it directly to the generator start motor. Always use a dedicated relay or auto-start module between the inverter dry contact and the generator. The relay amplifies the signal to the level required by the generator start system.

A hybrid inverter is the most complex single component in a solar installation. It has more terminals, more ports, and more settings than any other device in the system. Understanding every port and every function eliminates guesswork during installation and makes fault diagnosis straightforward when problems occur.

6.2  Battery Terminals (BAT+ and BAT-)
The battery terminals carry the highest continuous current of any connection on the inverter. For a 5kVA inverter on a 48V system, battery current can reach 100A under full load. Cable sizing and connection quality at these terminals is critical for both safety and performance.
Use the largest flexible cable the terminal will accept. Minimum 35mm2 for 5kVA systems. 50mm2 for 10kVA.
Use copper cable lugs crimped with a proper hydraulic crimping tool. Hammer crimps are not acceptable for battery connections.
Apply anti-oxidation compound to all copper connections to prevent terminal resistance increase over time.
Install an ANL fuse or DC breaker within 150mm of the battery positive terminal.
Connect the protective earth (PE) terminal to the battery rack and system earth.
6.3  AC Output Terminals
The AC output terminals supply power to all connected loads. In a hybrid system, this output can come from solar (via the inverter), battery (via the inverter), or grid (passed through the inverter with automatic voltage regulation). All these sources are seamlessly managed by the inverter.

The hybrid inverter has two AC input sources: the utility grid and an optional generator. These inputs allow the inverter to charge the battery from external AC sources when solar generation is insufficient.

Working Modes Explained (All Brands)
The working mode determines how the inverter prioritises its four possible power sources: solar panels, battery, grid, and generator. Selecting the wrong working mode is one of the most common reasons a solar system does not behave the way the client expects. This chapter explains every mode in detail and provides a brand comparison table.

10.1  Self-Use Mode (Recommended Default)
Self-Use mode is the most common and most appropriate mode for Nigerian hybrid solar installations. The inverter follows this priority: Solar panels power loads first. Any excess solar charges the battery. When solar is insufficient, battery supplements the loads. When both solar and battery are low, grid or generator provides the remaining power.

10.2  Time of Use Mode
Time of Use (TOU) mode adds a time-scheduling layer on top of Self-Use mode. The installer programs specific time windows for charging (from grid at cheap tariff) and discharging (supplying loads from battery when tariff is high). This mode requires battery communication for accurate SOC tracking.

10.3  Off-Grid Mode
Off-Grid mode disconnects the AC input (grid) from the system. The inverter operates entirely from solar and battery. No grid power is used or allowed into the system. The generator input (if available) can still be used in this mode. This mode is used for truly remote installations where no grid connection exists.
DANGER: Do Not Use Off-Grid Mode with Grid Connected
If an inverter is set to Off-Grid mode while still physically connected to the grid, the AC input protection circuit in the inverter may be bypassed. During a grid outage, the inverter may continue to supply power back onto the grid line, which creates a serious hazard for grid maintenance workers. Always disconnect the grid AC input cable physically when setting Off-Grid mode.
10.4  Backup Mode
In Backup mode, the grid powers all loads and charges the battery to 100%. The battery is only used when the grid fails. This mode maximises battery lifespan by keeping the battery fully charged and rarely discharging it. It is ideal for clients who only want solar as emergency backup and want to maximise battery longevity.
10.5  Grid-Tie Mode
Grid-Tie mode allows excess solar power to be exported to the utility grid. This mode requires anti-islanding protection (built into all modern hybrid inverters) and may require a net metering agreement with the electricity utility. Grid-tie mode is not commonly used in most African markets but is increasingly available as electricity regulations evolve.
10.6  Generator Priority Mode
Generator Priority mode charges the battery from the generator as the primary source, with solar supplementing the charge. This mode is used when the battery is very low and rapid recharging is needed. It overrides the normal solar-first priority to ensure the generator runs at its most efficient load point while charging.

11.3  Generator Charging Settings
The maximum charge current from the generator must be set to avoid overloading the generator. As a rule, never draw more than 70% of the generator rated power for battery charging. Leave 30% headroom for the generator to also supply loads simultaneously.
3kVA generator example:
3,000W x 0.70 = 2,100W available for charging
At 48V system:
2,100W / 48V
= 43.75A max charge current
Round down for safety:
Set max generator charge current to 40A
While running loads:
Generator supplies loads AND charges battery
Verify total does not exceed 3,000W
11.4  ATS (Automatic Transfer Switch) Function
Most hybrid inverters include an internal ATS that switches between grid, generator, and battery without interruption. The ATS transfer time is typically 10 to 20 milliseconds which is fast enough that most equipment does not notice the switch. However, some sensitive electronic equipment may be affected by even brief power interruptions.
Grid-to-battery transfer: nearly instantaneous, typically 10ms.
Generator-to-battery transfer: slightly longer due to generator startup time.
Generator start time: typically 3 to 10 seconds depending on generator model.
During generator startup: inverter supplies loads from battery until generator reaches stable voltage.

11.6  Tips and Common Generator Mistakes
COMMON MISTAKE: Connecting Generator to Grid AC Input Instead of GEN Input
Some installers connect the generator to the grid AC input instead of the dedicated GEN input. Always use the dedicated GEN input port where available.
TIP: Run Generator at Optimal Load
A generator operates most efficiently and reliably at 50 to 80% of its rated load. A 3kVA generator running at 30% load (charging a 48V battery at 20A) runs inefficiently, consumes more fuel per kWh, and accumulates carbon in the combustion chamber faster. Configure the generator charge current so the generator runs at 60 to 75% of its rated capacity when charging.

13.2  Three-Phase Inverter Wiring
Three-phase wiring requires careful attention to phase sequence. The three phases must be connected in the correct order (L1, L2, L3) to ensure three-phase motors rotate in the correct direction and three-phase equipment operates correctly.
Inverter 1 (Master): AC output connected to L1 phase of distribution board.
Inverter 2 (Slave 1): AC output connected to L2 phase of distribution board.
Inverter 3 (Slave 2): AC output connected to L3 phase of distribution board.
All three neutral outputs connected to common neutral busbar.
All three earth conductors connected to common earth busbar.
Communication cable daisy-chain: Master to Slave 1, Slave 1 to Slave 2.
All three inverters share the same battery bank via separate connections to battery busbar.
DANGER: Wrong Phase Sequence Causes Three-Phase Motor Damage
If the three phases are connected in the wrong sequence (L1-L3-L2 instead of L1-L2-L3), three-phase motors will rotate in the reverse direction. This can cause immediate mechanical damage to pumps and compressors. Always verify phase sequence with a phase sequence tester before energising any three-phase load for the first time.
13.3  Load Balancing Across Three Phases
In a three-phase solar system, each inverter handles the loads connected to its phase independently. If all heavy loads are on one phase, that inverter may overload while the other two inverters are lightly loaded. Good load balancing ensures all three inverters operate at similar power levels.
TIP: Balance Loads as Evenly as Possible
Divide the total loads approximately equally across the three phases. If the total load is 12kW, aim for approximately 4kW per phase. Single-phase loads (lights, fans, sockets) can be distributed across phases in the distribution board. Three-phase loads (motors) automatically draw from all three phases equally and do not require balancing.

System Expansion Guide
Solar systems are rarely static. Clients add new appliances, businesses grow, and energy needs evolve. A system that was correctly sized two years ago may need expansion today. System expansion done correctly is straightforward. Done incorrectly, it can create safety hazards, damage existing components, and void equipment warranties.
14.1  Adding More Panels to an Existing Array
Adding panels to an existing array requires checking several parameters before purchasing any new panels:
Check inverter maximum PV input current: the total current from all panel strings must not exceed this value.
Check inverter maximum PV input power: the total array wattage must not exceed this value (typically 120 to 150% of inverter rated power is acceptable).
Check MPPT voltage range: new panels must match the existing string voltage if being added to existing strings, or the new string voltage must be within the MPPT range.
Verify existing cables: adding more panels increases current. Existing cables may need upgrading.
Only add identical panels to existing series strings. Adding different panels to an existing string reduces the output of the existing panels.
14.2  Adding a Second Battery Bank
Expanding the battery bank increases backup time. The expansion requirements depend on the battery type and how many batteries are already installed.

15.1  How to Read Fault Codes

Some faults are self-clearing once the cause is resolved. Others require a manual reset.
Record the exact fault code from the display before attempting any reset.
Check if the fault is intermittent (comes and goes) or persistent (remains continuously).
Measure the relevant parameters (battery voltage, PV voltage, load current) with a multimeter.
Compare measurements to the fault code description to confirm the diagnosis.
Resolve the root cause before resetting the fault.

Cold Temperature String Voltage Calculation
The most common cause of MPPT controller failure in solar installations is not overload or surge. It is panel string voltage exceeding the MPPT maximum input voltage on a cold morning. Panel voltage rises as temperature falls. A string that is safely within the MPPT limit at 25 degrees C may exceed it by 15 to 20% on a cold harmattan morning at 5 degrees C.
Figure 21.1: Panel Voc versus temperature curve showing the danger zone below 10 degrees C. The STC (Standard Test Condition) measurement at 25 degrees C understates real-world maximum voltage. Always calculate cold Voc before finalising string design.
21.1  Why Panel Voltage Rises in Cold Weather
Solar panels are rated at Standard Test Conditions (STC): 1,000 W/m2 irradiance at 25 degrees C cell temperature. The temperature coefficient (Pmax) printed on the panel nameplate tells you by how much the panel output changes per degree of temperature change. For voltage, the coefficient is always negative, meaning voltage increases as temperature decreases.
Cold Voc = Nominal Voc x (1 + |Temp Coefficient| x (STC Temp - Minimum Temp) / 100)
Example: A panel with Voc = 45V and temperature coefficient of -0.35% per degree C. On a cold morning at 5 degrees C (20 degrees below STC temperature of 25 degrees C): Cold Voc = 45 x (1 + 0.35 x 20 / 100) = 45 x 1.07 = 48.15V per panel.
21.2  When This Matters in Nigeria
Nigeria is a tropical country and most locations rarely see temperatures below 15 degrees C. However, during the harmattan season (November to February), northern Nigeria can experience early morning temperatures as low as 5 to 8 degrees C. Combined with high altitude locations like Jos Plateau (which sees temperatures approaching 0 degrees C in December), the cold Voc calculation becomes very important.

Glossary of Configuration Terms
Term
Definition
ATS (Automatic Transfer Switch)
Internal switch in hybrid inverter that transfers between grid, generator, and battery supply without interruption.
BMS (Battery Management System)
Electronic circuit in Lithium batteries that monitors cell voltages, temperature, and controls charge and discharge.
CAN Bus
Controller Area Network. High-speed bidirectional communication protocol used between battery BMS and inverter.
Daisy Chain
Connecting devices in series (A to B to C) rather than all connected back to one point.
DoD (Depth of Discharge)
Maximum percentage of battery capacity safely usable before recharging. Lithium: 80%, Lead-acid: 50%.
Dry Contact
Low-current switching output on inverter for controlling external devices via relay.
MPPT (Maximum Power Point Tracking)
Algorithm in charge controller that continuously adjusts operating point to maximise panel power output.
Modbus
Serial communication protocol used over RS485 for device data exchange.
Parallel Communication
Proprietary cable between parallel inverters that synchronises their output frequency, voltage, and phase.
RS485
Serial communication standard using differential signalling for noise-resistant long-distance data transmission.
Self-Use Mode
Inverter operating mode: solar powers loads first, excess charges battery, grid used as last resort.
SOC (State of Charge)
Percentage of remaining battery capacity expressed as a percentage of total capacity.
String
Series connection of solar panels. Voltage = sum of panel voltages.
TOU (Time of Use)
Inverter mode that charges and discharges battery at scheduled times to maximise cost savings.
Vmp
Maximum power voltage. The panel operating voltage at maximum power output. Used for MPPT range check.
Voc
Open circuit voltage. Maximum voltage a solar panel produces with no load connected. Used for string design.
